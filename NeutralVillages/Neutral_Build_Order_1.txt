# Neutral village build order 1
#
# Neutral villages build from a file like this one. Every file in this
# folder called Neutral_Build_Order_1.txt, Neutral_Build_Order_2.txt,
# Neutral_Build_Order_3.txt and so on is one build order; each neutral
# village picks one of them at random when the game starts.
#
# Lines that start with # are notes.
#
# --- What it may build, and the most of each ---------------------------------
# One building a line:   Asset name (Gameplay name) = most
# The asset name is the model and never changes. The gameplay name in
# brackets is only a reminder of what the model does (Names.txt decides
# that). The most counts everything of that kind the village has,
# including the Storehouse it starts with. A building left out, or set
# to 0, is never built.
