# SpriteSquirter

A 3D sandbox experiment built with [Godot 4](https://godotengine.org). A giant
two-legged creature stomps around a procedurally generated island full of
funky villages and tiny villagers, and casts **fireball** to blow things up
and start fires. The long-term plan is to grow it into an RTS / tower-defense
game (see [docs/ROADMAP.md](docs/ROADMAP.md)).

The art direction is **stylised realism**: rounded, detailed shapes with
painterly textures, lush wind-blown grass, warm sunlight, soft fog and
lighting "moods" that shift the whole palette. See
[docs/ART_STYLE.md](docs/ART_STYLE.md).

Everything is generated by code: buildings, trees, textures, even the
creature model. No 3D modelling tools are needed to run or change it.

## Running it

1. Download **Godot 4.7** (standard build, not .NET) from
   <https://godotengine.org/download>. It is free and needs no install, so just unzip and run it.
2. In the Godot Project Manager click **Import**, choose this folder's
   `project.godot`, then **Import & Edit**.
3. Press **F5** (or the ▶ button) to play.

The first import takes a few seconds while Godot builds its cache in `.godot/`.

## Controls

| Input | Action |
|---|---|
| WASD / arrow keys | Pan camera (hold Shift for faster) |
| Q / E | Rotate camera |
| Mouse wheel | Zoom |
| Middle mouse drag | Rotate and tilt camera |
| Space | Jump the camera to the creature |
| Right click | Walk the creature to that spot |
| F | Cast fireball at the cursor (any tool) |
| 1–7 | Tools: Command, Fireball, Raise, Lower, Flatten, Smooth, Build |
| [ / ] | Brush size for terrain tools |
| R | New random design while in Build mode |
| Esc | Back to Command tool |
| L | Change the lighting mood (day, golden hour, misty dawn, night) |
| G | Grass detail (High / Medium / Low / Off): lower it if the frame rate drops |
| N | Generate a brand-new world |

## What's in the demo

- **Terrain:** a noise-based island with hills, lakes, beaches, cliffs and
  flat village sites linked by dirt roads. You can sculpt it live (raise,
  lower, flatten, smooth), and fireballs leave craters and scorch marks.
  Dense grass sways in the wind and burns away where fire has been.
- **Funky buildings:** five generated styles (crooked timber cottages,
  leaning wizard towers, mushroom houses, turf-roofed burrows, gourd
  houses) in stone, plaster, timber, shingles and thatch. You can place
  more by hand with the Build tool. Each new house brings two villagers.
- **Tiny villagers:** they wander around their village, panic when the
  creature or fire comes near, catch fire, get flung by explosions and get
  squashed flat by footsteps.
- **The creature:** a 14 m horned beast with about 100,000 triangles on a
  skeleton. Walking is procedural: feet plant on the terrain with two-bone
  IK, and the body, arms, head, jaw and tail react. Its footsteps shake the
  camera and crush whatever they land on.
- **Fireball:** an arcing projectile that explodes and digs a crater. It
  breaks buildings and trees into physics debris (Jolt), and sets fires
  that spread across grass, char buildings and eventually collapse them.
- **Lighting moods:** meadow day, golden hour, misty dawn and night, with
  volumetric fog, glowing windows and firelight.

## Project layout

```
project.godot              Engine settings (Forward+, Jolt physics, autoload "Game")
scenes/main.tscn           The only scene; everything else is built in code
shaders/                   Terrain, grass, surfaces, foliage, water, sky, creature, particles
assets/textures/           Baked textures (made by tools/bake_textures.gd)
assets/creature/           The creature model (made by tools/bake_creature.py)
tools/                     Scripts that generate the assets above
scripts/
  main.gd                  World setup, input, tools, building placement
  core/game.gd             Autoload: global access to terrain, effects, camera...
  core/art.gd              Palette and every material, in one place
  core/mesh_builder.gd     Builds rounded meshes in code (lathes, tubes, blobs...)
  world/terrain.gd         Heightmap, chunked mesh, collision, sculpt brushes, raycast
  world/grass.gd           Instanced grass with distance-based detail
  world/atmosphere.gd      Sun, sky, fog and the lighting moods
  world/building_factory.gd  The five building styles
  world/flora_factory.gd   Trees, bushes and boulders
  world/destructible.gd    Shared burn / damage / shatter behaviour
  world/world_populator.gd Places villages, villagers, trees and rocks
  world/fire_system.gd     Spreading ground fires
  units/creature.gd        The giant: locomotion, skeleton posing, IK
  units/villager.gd        Villager looks and state machine
  spells/fireball.gd       Projectile
  spells/explosion.gd      Blast gameplay: damage, craters, flinging, fires
  fx/effects.gd            Particles, flashes, dust, debris bodies
  fx/fire_emitter.gd       A single flickering fire
  camera/rts_camera.gd     RTS-style orbit camera
  ui/hud.gd                Toolbar, hints, stats
```

### Regenerating assets

The textures and the creature are generated files that are checked in, so
you only need these when you want to change them:

```bash
godot --path . -s tools/bake_textures.gd
```

```bash
pip install numpy scikit-image
```

```bash
python3 tools/bake_creature.py
```

### Conventions

- GDScript with static types everywhere (`var x := ...`, typed arguments).
- One `class_name` per script. Shared systems are reached through the `Game`
  autoload instead of node paths.
- Units are metres. Local +Z is "forward" for the creature and buildings.
- Tunable numbers are `const` or `@export` at the top of each script.

## Tech notes

- **Engine:** Godot 4.7, Forward+ renderer (needed for the volumetric fog),
  Jolt physics.
- **Performance:** built for a mid-to-high-end desktop GPU. Grass is the
  heaviest part; press G to lower it. Debris pieces fade out after about
  10 s, and the number of fires and fire lights is capped.
- Trees, buildings and villagers are still individual nodes (about 300
  trees, 40 buildings, 100 villagers). Instancing them is on the roadmap
  for RTS-scale unit counts.
